- `go list -deps -json ./...` resolved 128 packages and reported zero packages with CgoFiles, including `github.com/boxesandglue/textshape v0.0.15`. This materially lowers native-dependency risk inside Folio; cgo is introduced only by the proposed export bridge. Evidence: command executed in `/Users/panitw/Projects/folio/folio-go` on 2026-08-28. Confidence: high. Class: implementation.
- With `GOOS=windows GOARCH=amd64 CGO_ENABLED=0`, the current Folio CLI compiled successfully into a 20 MB PE32+ x86-64 executable. This proves the renderer dependency graph compiles for Windows amd64 as pure Go, but does not prove the proposed c-shared bridge, which needs a Windows-compatible C compiler. Evidence: build executed against the current repository on 2026-08-28. Confidence: high. Class: implementation.
- Go 1.21 and later require Windows 10 or Windows Server 2016 or newer. A Folio wrapper built with its pinned Go 1.26 toolchain therefore cannot serve older operating systems even if those systems can run .NET Framework 4.6. Source: https://go.dev/wiki/MinimumRequirements (Go project; accessed 2026-08-28). Confidence: high. Class: version/compatibility.
- Starting with Go 1.25, Windows cgo requires a C compiler with DWARF 5 support; GCC builds need binutils 2.37 or later. The release pipeline must pin a qualifying compiler. Same Go source. Confidence: high. Class: version/compatibility.
- Go's build implementation explicitly supports `c-shared` on Windows, and official command documentation requires one main package and cgo-exported functions. Sources: https://go.dev/src/cmd/go/internal/work/init.go and https://go.dev/cmd/go/ (Go project; accessed 2026-08-28). Confidence: high. Class: version/compatibility.
- Go 1.26.0 is no longer the current stable Go release as of 2026-08-28; Go 1.27.0 was released 2026-08-19, while the repository deliberately pins 1.26.0 for PDF byte reproducibility. This is an intentional reproducibility/security-maintenance tradeoff that should be documented and periodically reassessed. Sources: repository `go.mod` and https://go.dev/doc/devel/release (Go project; accessed 2026-08-28). Confidence: high. Class: ecosystem.

Round stopped on coverage: the current codebase's Windows portability is established, while actual c-shared export/packaging remains correctly assigned to the proposed proof of concept.
