- (decision) Determinism = Promise B, byte-identical. Same template+data+folio-go version yields an identical file hash. Chosen over layout-only; makes golden-file regression testing a hash compare and matches 'reliability over feature breadth'.
- (decision) Preview engine = folio-go compiled to WebAssembly, running in the browser tab. Exact production renderer, fully offline, nothing leaves the user's machine. Completes the draw.io model.
- (decision) IMPLICATION of B+WASM: browser preview must be byte-identical to native server render. Elevates 'WYSIWYG' from approximation to a provable hash equality — Folio's signature claim, and the hardest constraint in the build. Forbids cgo, demands identical font subsetting and float behavior across WASM and native targets.

- (decision) NFR1 rewritten as NFR1.a-1.g arithmetic constraints per feasibility review: fixed-point integer layout math (structural, not disciplinary), quantized numeric emission, restricted numeric surface banning math transcendentals, no map iteration in emission, pure render function.
- (decision) Font library constraint is now a determinism requirement: tdewolff/font stamps time.Now() into head.modified and produces different bytes every run — disqualified. boxesandglue/textshape (MIT) is byte-stable with a determinism test and half the wasm size. Subset tags must be a deterministic hash, which PDF spec ISO 32000-1 9.6.4 permits ('arbitrary' letters).
- (decision) Thai line breaking confirmed build-it-yourself: every Go UAX#14 impl defers Thai (SA class) and every pure-Go Thai segmenter is dead, unlicensed, or reads its dict via runtime.Caller (fatal in wasm). Embed ICU thaidict as BytesTrie ~123KB under Unicode License.
- (decision) Q1 ANSWERED: byte-identical PDF is achievable AND spec-conforming. ISO 32000-1 §14.4 NOTE: 'The calculation of the file identifier need not be reproducible.' /ID is a should, not a shall, in PDF 1.7. Verified reproducible across separate OS processes: boxesandglue (BSD-3) and signintech/gopdf (MIT, deterministic by default).
- (decision) MVP must not encrypt PDFs: ISO 32000-1 §7.6.2 Algorithm 1(d) mandates a random 16-byte IV per string/stream, making encrypted output inherently nondeterministic. Encryption and NFR1 are mutually exclusive.
- (decision) Adopt SOURCE_DATE_EPOCH as the reproducible-builds convention for pinning document dates, following Typst, pdfTeX, ReportLab and boxesandglue.
- (change) Corrected an error I introduced: FMA contraction is an ARCHITECTURE property, not an OS one. arm64 contracts (measured on darwin/arm64), amd64 and wasm do not. The earlier 'linux/arm64 is the only target that contracts' framing was wrong and would have produced the wrong CI matrix. Fixed in NFR1, R1 and addendum §N.
