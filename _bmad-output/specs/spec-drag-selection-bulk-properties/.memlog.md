- (constraint) A group move starts by an unmodified primary-pointer drag on any already-selected component body and must not collapse selection at pointerdown or release. A selected table body also starts the group move; its internal column selection must not steal the gesture. Resize and editor controls retain explicit precedence.

- (constraint) Group movement is a distinct document mutation from local rectangle selection. Exactly one atomic engine transaction updates all captured targets; validation failure leaves all unchanged. One undo restores every original position, and redo reapplies the same accepted move.
- (constraint) Snap on uses the pressed element origin as the reference and derives one common snapped delta for every member; never independently snap or clamp member positions, which would distort spacing. Snap off keeps precise shared movement.

- (assumption) A-7: Snap reference is the origin of the pressed selected element in its band/column coordinates. - (assumption) A-8: An unmodified click on a member of a multi-selection leaves that selection intact; dragging an unselected element selects and moves only it.
