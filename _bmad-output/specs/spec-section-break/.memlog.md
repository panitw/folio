- (direction) User: add boolean option Anchor to the Section Break. Anchor true locks the section to its declared position on the page; Anchor false lets content above push the section down, which then sits right at the pushed boundary.
- (capability) CAP-7: author sets Anchor per break; Anchor false makes the below-line section follow the end of above-line content on the same page instead of jumping to a new page.
- (decision) Anchor false, content above ends below the line: the break line moves to where that content ends; each section element keeps its offset from the line, so the designed gap survives (user choice).
- (decision) Anchor false, pushed section does not fit in the room left on that page: the whole section moves to a new page and the line sits at the top of that page's content window, offsets kept (user choice).
- (decision) Anchor defaults to true, so existing behaviour and files are unchanged; the key is written only when false and folds into unreleased format 4.1 with no extra bump (user choice).
- (assumption) Anchor false never pulls the section up: when above-line content ends at or above the line, the section sits at its declared y, exactly as anchored, keeping CAP-3 byte identity.
- (assumption) Fit test for Anchor false: section fits if its declared extent below the line (lowest declared member bottom, table minHeight floor included) fits in the room left; a section taller than a whole window then continues from the top of its new page under the window rules.
- (assumption) .folio key sectionBreakAnchor, optional boolean on the content band, camelCase like keepTogether; present without sectionBreak is SECTION_BREAK_INVALID naming the band; an explicit true canonicalises away on save.
- (assumption) Designer: Anchor is a checkbox in the Section Break Properties panel, checked by default, one engine command and one undo entry; the canvas line and tab look the same either way.
- (note) Anchor false supersedes, for unanchored breaks only, the rigid whole-page-only movement, declared-y, and no-move-to-top-of-page rules; anchored breaks keep them unchanged.
